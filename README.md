# Calculadora Estadística en C++ con Lista Enlazada

## Descripción

Este proyecto es un programa escrito en C++ que permite calcular la **media** y la **desviación estándar** de un conjunto de números introducidos por el usuario. Los números se almacenan en una **lista enlazada**, y las operaciones estadísticas se realizan a partir de estos datos.

### Características:
- Inserción de números en una lista enlazada.
- Cálculo de la **media** de los números.
- Cálculo de la **desviación estándar**, con la corrección de Bessel para una estimación más precisa de la desviación estándar muestral.
- Liberación de memoria de la lista enlazada después de su uso.
